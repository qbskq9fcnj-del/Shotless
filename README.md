# Shotless

ショートカットキーで全画面を撮影し、**クリップボードにだけ**入れるアプリです。画像ファイルは一切保存しません。Windows / Mac 対応。

## 使い方

1. 起動するとトレイ(Mac はメニューバー)に常駐します。
2. `Ctrl + Shift + S`(Mac は `Cmd + Shift + S`)を押します。
3. マウスがあるモニターの全画面が撮影され、クリップボードに入ります。音とフラッシュで撮影を知らせます(通知は出ません)。
4. 好きなアプリに貼り付けて使います。
5. 終了はトレイのメニューから「終了」を選びます。

## 仕様

- 撮影範囲: マウスがあるモニターの全画面(範囲選択はありません)
- 出力先: クリップボードのみ。ディスクへの書き込みは行いません(コードで `fs` を使っていません)
- 通知: 出しません(音とフラッシュのみ)

## Mac の注意

初回の撮影時に「画面収録」の権限が必要です。`システム設定 > プライバシーとセキュリティ > 画面収録` で Shotless を許可し、アプリを再起動してください。

## 注意

- クリップボード履歴機能(Windows の `Win + V` など)を使っていると、OS 側に履歴が残ることがあります。
- スマホなどで画面を撮影するのは防げません。

## 開発

```sh
npm install
npm start        # ビルドして起動
npm run dist     # インストーラを release/ に作成
```

`v*` のタグを push すると、GitHub Actions が Windows 用と Mac 用をビルドして Releases に載せます。
