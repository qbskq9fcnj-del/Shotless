# Shotless

全画面を撮影して、**クリップボードにだけ**入れるアプリです。画像ファイルは一切保存しません。Windows / Mac 対応。

## 使い方

1. 起動するとトレイ(Mac はメニューバー)に常駐します。
2. `Ctrl + Shift + S`(Mac は `Cmd + Shift + S`)を押します。
3. マウスがあるモニターの全画面が撮影され、クリップボードに入ります。音とフラッシュで撮影を知らせます(通知は出ません)。
4. 好きなアプリに貼り付けて使います。
5. 終了はトレイのメニューから「終了」を選びます。

## 設定

トレイのアイコンから「設定…」を開きます。

| 項目 | 内容 |
|---|---|
| ショートカットキー | 入力欄をクリックして、使いたいキーを押します。「既定に戻す」で `Ctrl/Cmd + Shift + S` に戻ります。 |
| 切り替え時の自動撮影 | オンにすると、対象アプリに切り替えた瞬間に、**切り替える直前の画面**を自動でクリップボードに入れます。**音もフラッシュも出ません。** 既定はオフです。 |
| 負荷の軽さ | 自動撮影の頻度と画質を選びます。**軽い**(約4秒ごと・画質50%)/ **標準**(約2秒ごと・画質75%、既定)/ **鮮度重視**(約1秒ごと・画質100%)。 |
| 対象アプリ | 1行に1つ。アプリ名かウィンドウタイトルに、その文字が含まれていれば対象です(大文字小文字は区別しません)。既定は `Claude` です。 |
| ログイン時に自動起動 | パソコンにログインしたとき、自動でトレイに常駐します。既定はオフです。 |

### 切り替え時の自動撮影について

たとえば、ブラウザで見ていた画面を Claude に貼りたいとき、ショートカットを押さなくても、Claude に切り替えて `Ctrl/Cmd + V` を押すだけで貼れます。

- オンの間、対象アプリが前面でないときは、画面を**メモリ上に1枚だけ**保持します。ディスクには保存しません。
- 負荷を抑えるため、画面が変わらない間は撮影の間隔を自動で延ばし、マウスもキーも5秒動かさなければ、撮影を止めます。
- 対象アプリに切り替えるたびに、クリップボードが上書きされます。文字を貼りたいときは、トレイの「切り替え時に自動撮影」のチェックを外してください。
- 貼り付けられるのは、切り替える数秒前までの画面です(「負荷の軽さ」で変わります)。画面を変えた直後に切り替えると、変える前の画面が貼られることがあります。
- 自動撮影の画質は、「負荷の軽さ」の設定に従います。ショートカットでの撮影は、いつも100%です。
- ショートカットで撮影した場合は、これまでどおり音とフラッシュが出ます。

## 仕様

- 撮影範囲: マウスがあるモニターの全画面(範囲選択はありません)
- 出力先: クリップボードのみ。画像をディスクに書き込むことはありません
- 保存されるもの: 設定(`settings.json`)だけです
- 通知: 出しません

## Mac の注意

初回の撮影時に「画面収録」の権限が必要です。`システム設定 > プライバシーとセキュリティ > 画面収録` で Shotless を許可し、アプリを再起動してください。自動撮影も、同じ権限を使います。

## 注意

- クリップボード履歴機能(Windows の `Win + V` など)を使っていると、OS 側に履歴が残ることがあります。
- スマホなどで画面を撮影するのは防げません。

## 開発

```sh
npm install
npm start        # ビルドして起動
npm run dist     # インストーラを release/ に作成
```

`v*` のタグを push すると、GitHub Actions が Windows 用と Mac 用をビルドして Releases に載せます。
