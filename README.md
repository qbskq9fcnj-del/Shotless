# Shotless

ショートカットで全画面を撮影して、そのままクリップボードに入れるアプリです。Mac 対応。

## ダウンロード

[Releases](https://github.com/qbskq9fcnj-del/Shotless/releases) から Mac 用の `.dmg` をダウンロードします(Apple Silicon の Mac 用です。Intel の Mac には対応していません)。開いて Shotless を Applications にドラッグしてください。Apple の署名・公証済みです。Windows 版は今のところありません。

## 使い方

1. 起動するとトレイ(Mac はメニューバー)に常駐します。
2. `Ctrl + Shift + S`(Mac は `Cmd + Shift + S`)を押します。
3. マウスがあるモニターの全画面が、その瞬間に撮影され、そのままクリップボードに画像が1枚入ります。音とフラッシュで知らせます(通知は出ません)。
4. 好きなアプリで `Cmd + V`(Windows は `Ctrl + V`)を押して貼り付けます。
5. 終了はトレイのメニューから「終了」を選びます。

## 設定

トレイのアイコンから「設定…」を開きます。

| 項目 | 内容 |
|---|---|
| ショートカットキー | 入力欄をクリックして、使いたいキーを押します。「既定に戻す」で `Ctrl/Cmd + Shift + S` に戻ります。修飾キー(Ctrl / Alt / Shift / Command)と一緒に押す必要があります(F1〜F24 は単独でも可)。 |
| ログイン時に自動起動 | パソコンにログインしたとき、自動でトレイに常駐します。既定はオフです。インストールしたアプリでだけ働きます。 |

## 仕様

- 撮影範囲: マウスがあるモニターの全画面(範囲選択はありません)
- 出力先: クリップボードだけです。画像ファイルは作りません。撮った画像はメモリの上だけにあり、次に撮るまでクリップボードに残ります
- 保存されるもの: 設定(`settings.json`)だけです
- 通知: 出しません
- ショートカットを押したときだけ撮影します。常時の撮影や監視はしません

## Mac の注意

初回の撮影時に「画面収録」の権限が必要です。`システム設定 > プライバシーとセキュリティ > 画面収録` で Shotless を許可し、アプリを再起動してください。許可は、Shotless に付けてください。

## 注意

- クリップボード履歴機能(Windows の `Win + V` など)を使っていると、OS 側に画像の履歴が残ることがあります。
- スマホなどで画面を撮影するのは防げません。

## 開発

```sh
npm install
npm start        # ビルドして起動
npm run dist     # インストーラを release/ に作成
```

`v*` のタグを push すると、GitHub Actions が Mac 用をビルド・署名・公証して Releases に載せます。
